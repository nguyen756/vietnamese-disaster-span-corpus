# Executed LLM runner source, archived for inspection

These files preserve the actual Qwen CPU and Luna API runner algorithms.
No live run configuration, blind source inputs, credentials, ledger or model
weights are distributed here. They are not a turnkey launch package. Follow
docs/EXPERIMENTS.md; reconstruct fixed prompts and obtain input text first.
Old prices/expiry values are historical records, not current API pricing.
No install/test command launches generation or purchases model access.
