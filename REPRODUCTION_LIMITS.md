# What this release reproduces

Offline scripts recompute the reported observed LLM, original human-agreement,
E4 consistency and Gold/E6 recurrent scores from text-free reference/prediction
records. Optional oracle simulation uses the exact executed gating functions.
All core sentences and P2 were locally reconstructed from preserved sources;
this does not demonstrate recovery from today's public URLs.

Full training or fresh LLM generation needs exact source text, upstream assets
and compute/API access. Trained weights and raw article snapshots are absent.
The original server source is preserved for inspection/adaptation; historical
manifests/configuration paths refer to the private server project. This release
does not claim a freshly rerun turnkey training installation on another host.
Software license is undecided, so this is public code, not a licensed open-source
release. Publication preparation did not retrain or buy inference.
